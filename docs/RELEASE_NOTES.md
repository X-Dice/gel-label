# GelLabel v0.1.0 — initial preview

Label a gel image without installing software or uploading files.

- Paste lane names from Excel and adjust each label independently.
- Add plain text, arrows, group brackets, and manually entered band-size labels.
- Export self-contained SVG, PNG up to 2×, or a JSON project to reopen later.
- Use English or Simplified Chinese.
- Keep image bytes unchanged and annotations separate.
- Download the single-file offline HTML; no account or server required.

All included examples are synthetic and retain a demo watermark. This version does not measure bands or modify image pixels.

This is a **preview**. Automated model/render tests and production build checks passed. Browser interaction and offline-file execution remain unverified because browser access was denied during preparation. See `docs/VERIFICATION.md` for the acceptance checklist and limitations.

# Share drafts — v0.1.0 preview

These drafts have not been posted. Repository, release, and Pages deployment are confirmed. Real browser acceptance is still pending, so the drafts identify this as an early preview.

## English

I made an early preview of GelLabel, a small open-source tool for labeling gel images in the browser.

Paste a column of lane names from Excel, move them into place, add arrows or group brackets, and export SVG or PNG. You can save a project and reopen it later. Files stay in the browser, and there's a single-file offline version too.

It doesn't quantify bands or edit the image pixels — it focuses on making the labeling step easier.

Try it: https://x-dice.github.io/gel-label/
Code: https://github.com/X-Dice/gel-label

If you work with gel images, I'd like to know what would make it more useful. A star is welcome if it saves you some time.

## 中文

我做了一个开源小工具 GelLabel，目前是早期预览版，用来给电泳胶图加标注。

可以直接粘贴 Excel 中的一列泳道名称，拖动调整位置，再添加箭头、分组括号，导出 SVG 或 PNG。保存项目后还能继续编辑。文件在浏览器里处理，也有单文件离线版。

它不做条带定量，也不修图，主要是想让标注和排版方便一点。

试用：https://x-dice.github.io/gel-label/
源码：https://github.com/X-Dice/gel-label

如果你平时也需要标注胶图，欢迎试用和提建议。觉得有用的话，也欢迎给一个 Star。

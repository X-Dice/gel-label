# Contributing

Thanks for helping make GelLabel useful.

1. Open an issue describing the task, expected behavior, and current behavior.
2. For a small fix, make a focused branch and keep the pull request easy to review.
3. Run `npm ci`, `npm test`, and `npm run build` before submitting.
4. For editor changes, manually check image import, lane-label pasting, dragging, undo/redo, exports, and project reopening in a browser. Include the browser and operating system tested.
5. Update English and Chinese interface strings together. Avoid new runtime services or uploading files.

Synthetic fixtures are preferred. Do not attach private, unpublished, or identifying experiment data without permission. Never commit credentials. Do not remove the synthetic-data watermark from demo exports.

Useful contributions include keyboard interaction fixes, accessible controls, browser compatibility reports, and focused regression tests. Large changes should start with an issue. Automatic measurement and image alteration are outside the first version's scope.

Original contributions are accepted under the project's MIT license. Be respectful and keep feedback specific.
